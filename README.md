# 🥗 Nutrient Tracker

A Flutter-based mobile application designed to help users track their daily nutrition and maintain healthy eating habits.

## 📱 About the Project

**Nutrient Tracker** allows users to record their food intake and monitor important nutrients such as calories, protein, carbohydrates, fats, water, vitamins, and minerals.

The project is developed using **Flutter and Dart** with a clean and user-friendly interface.

## ✨ Features

- 🍎 Add and manage food items
- 🔥 Track daily calorie intake
- 💪 Track protein, carbohydrates, and fats
- 💧 Track daily water intake
- 📊 View nutrient progress
- 🎯 Set daily nutrition goals
- 📅 Monitor daily food records
- 📱 Responsive Flutter UI

## 🛠️ Technologies Used

## 🚀 Getting Started

### Prerequisites

Make sure you have Flutter installed on your system.

Check your Flutter installation:

```bash
flutter doctor
```

### Installation

1. Clone this repository:

```bash
git clone <your-repository-url>
```

2. Open the project folder:

```bash
cd nutrient_tracker
```

3. Install dependencies:

```bash
flutter pub get
```

4. Run the application:

```bash
flutter run
```

## 🎨 Main Screens

- **Home Screen** – Displays daily nutrition summary and progress.
- **Add Food Screen** – Allows users to add food and nutrient information.
- **Nutrition Screen** – Shows detailed nutrient tracking.
- **Profile Screen** – Manages user information and nutrition goals.
